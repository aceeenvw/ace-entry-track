# ⊹ ACE Entry Track ⊹

See which lorebook entries [SillyTavern](https://github.com/SillyTavern/SillyTavern) activated in each reply, and test what a line of dialogue would match before you send it.

## Features

- **Activation panel:** Open the floating book button after a reply to see active entries grouped by lorebook, what changed since the last generation, and whether World Info hit its token budget.
- **Match details:** Expand an entry to see which keys the tracker found in chat, persona, character fields, or other scan sources. SillyTavern confirms the activation; the highlighted matches help explain it.
- **Lorebook scratchpad:** Choose a book, paste dialogue, and select **Test lorebook**. Results list each matching entry with its primary and secondary key hits. No message is sent.
- **Regex tools:** Check a keyword list for malformed expressions, preview variants, or turn a list of words and phrases into a regex.

## Quick Start

In **Extensions → Install Extension**, paste `https://github.com/aceeenvw/ace-entry-track`. Open **Extensions → ACE Entry Track** for the scratchpad, regex tools, and panel settings. Leave the monitored lorebook boxes unchecked to track all attached books.
